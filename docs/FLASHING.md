# Установка Meshtastic E290 InkHUD RU

Поддерживается **Heltec Vision Master E290**, ESP32-S3, таблица разделов на 8 MB, 2,9″ E-Ink, штатная распиновка upstream. Не использовать для E213, T190 или другой платы. Прошивка основана на **2.7.26.54e0d8d Beta**. Проверена чистая установка на E290 с физической Flash 16 MB, запуск, USB API и работа дисплея. Радиообмен, дальность и энергопотребление не измерялись.

В этом комплекте меню, подсказки, статусы и уведомления InkHUD — на русском. Внутренняя версия остаётся `2.7.26.54e0d8d`; используйте файлы именно из этого комплекта и сверяйте SHA-256.

## Подготовка инструментов (macOS, Linux, Windows)

Распакуйте `meshtastic-e290-inkhud-ru.zip`. Все команды записи выполняются из папки `dist/`. Вместо примера `/dev/cu.usbmodemXXXX` везде подставляйте свой порт: macOS `/dev/cu.usbmodem...`, Linux `/dev/ttyACM0`, Windows `COM5`. Скрипт запуска также принимает Windows/Linux-порты.

Создайте отдельное Python-окружение:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install esptool==4.11.0
python -m serial.tools.list_ports
```

В Windows используйте `py -m venv .venv`, затем `.venv\Scripts\activate.bat` в cmd или `.venv\Scripts\Activate.ps1` в PowerShell; остальные команды выполняются через `python`.

## 1. Проверка устройства и резервная копия

Сверьте маркировку E290 на плате, аппаратную ревизию и модель радиомодуля с [документацией Heltec/Meshtastic](https://meshtastic.org/docs/hardware/devices/heltec-automation/vision-master/). Если ревизия отличается от поддерживаемой официальным E290 InkHUD, сначала проверьте её совместимость с upstream. Перед питанием подключите подходящую LoRa-антенну. Используйте USB-кабель с передачей данных.

Пока работает прежняя прошивка, сохраните настройки и сведения о версии. Подставьте свой порт вместо `/dev/cu.usbmodemXXXX`; в Windows это, например, `COM5`.

```sh
meshtastic --port /dev/cu.usbmodemXXXX --export-config > e290-config.yaml
meshtastic --port /dev/cu.usbmodemXXXX --info > e290-info.txt
```

CLI устанавливается через `python3 -m pip install 'meshtastic[cli]'` в отдельное Python-окружение. [Официальное описание экспорта](https://meshtastic.org/docs/software/python/cli/#--export-config). Проверьте, что YAML непустой, сохраните URL всех каналов и их ключи отдельно, если они не попали в экспорт. Храните копии конфиденциально. Экспорт конфигурации не является побайтовой копией Flash и не гарантирует сохранение идентичности узла при стирании.

Определите физический размер Flash командой `python -m esptool --chip esp32s3 --port PORT flash_id`. Для полной копии используйте обнаруженный размер: **8 MB → `0x800000`, 16 MB → `0x1000000`**. На проверенном E290 обнаружено 16 MB; прошивка использует первые 8 MB. Пример резервного копирования 16 MB:

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX read_flash 0x0 0x1000000 e290-full-backup.bin
```

Этот файл содержит ключи и настройки. Не публикуйте его. Не восстанавливайте побайтовую копию на другое устройство.

## 2. Проверка комплекта

В каталоге `dist/` выполните на macOS/Linux:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Назначение файлов:

| Файл | Назначение | Адрес |
|---|---|---|
| `meshtastic-e290-inkhud-ru.bin` | Только приложение, обновление с сохранением разделов настроек | `0x10000` |
| `meshtastic-e290-inkhud-ru.factory.bin` | Штатный объединённый bootloader + partitions + boot_app0 + приложение | `0x0` |
| `mt-esp32s3-ota.bin` | Официальный вспомогательный OTA-образ из релиза 2.7.26 | `0x340000` |
| `littlefs-e290-inkhud-ru.bin` | Файловая система для чистой установки | `0x670000` |

`factory.bin` сам по себе **не содержит** вспомогательное OTA-приложение и LittleFS. Для чистой установки нужны все три соответствующих файла. Обычный `.bin` нельзя писать по адресу 0x0, а `.factory.bin` — по адресу 0x10000.

## 3. Режим загрузчика ESP32-S3

Закройте Meshtastic-клиенты и программы, занявшие последовательный порт. В Web Flasher попробуйте `1200bps reset`. Если он не сработал: отключите USB, удерживайте **BOOT**, подключите USB, отпустите BOOT через 2–3 секунды. Если плата продолжает питаться от аккумулятора, удерживайте BOOT и кратко нажмите RESET, затем отпустите BOOT. Порт в режиме загрузчика может измениться.

## 4. Официальный Meshtastic Web Flasher

1. Откройте [flasher.meshtastic.org](https://flasher.meshtastic.org/) в Chrome или Edge.
2. Выберите **Heltec Vision Master E290**. Для официальной прошивки выберите вариант **InkHUD**.
3. Для обновления уже работающего E290 с совместимой таблицей разделов загрузите локальный файл **`meshtastic-e290-inkhud-ru.bin`** через выбор собственного файла.
4. Выберите **Update**, оставьте **Full erase / Erase and install** выключенным. В журнале должна быть запись приложения по адресу **0x10000**, без полного стирания.
5. Подключите правильный USB-порт, дождитесь окончания, затем нажмите RESET или переподключите устройство.

Для установки с нуля через Web Flasher сначала установите официальный **2.7.26 E290 InkHUD** с полной установкой, затем выполните обновление локальным RU `.bin` по шагам выше. Это удалит прежние настройки на первом шаге. Если сайт больше не предлагает эту версию, используйте CLI ниже.

Не используйте одиночный локальный `.factory.bin` в режиме полной установки Web Flasher: изученный код его legacy-пути получает вспомогательные образы через ту же функцию чтения выбранного файла, что может привести к повторной записи этого файла в другие разделы. В этом комплекте предусмотрены явные CLI-команды. [Код официального Web Flasher](https://github.com/meshtastic/web-flasher/blob/main/stores/firmwareStore.ts).

## 5. CLI: обновление с сохранением настроек

В отдельном Python-окружении установите `esptool==4.11.0`. Следующие команды используют синтаксис именно этой версии. Команды подготовлены по штатным скриптам и проверенной таблице разделов; запись и запуск на физическом E290 выполнены успешно.

```sh
python -m pip install esptool==4.11.0
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX flash_id
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX --baud 115200 --after no_reset write_flash 0x10000 meshtastic-e290-inkhud-ru.bin
python start_firmware.py --port /dev/cu.usbmodemXXXX
```

Проверьте, что обнаружен ESP32-S3 с Flash не менее 8 MB. Обновление записывает только app0; NVS, LittleFS и таблица разделов остаются на месте. Предполагается стандартная таблица E290: app0 `0x10000/0x330000`, app1 `0x340000/0x330000`, LittleFS `0x670000/0x180000`. При другой таблице или неизвестной исходной прошивке сначала сделайте полный backup и используйте чистую установку.

Переход с 2.8 на эту 2.7-сборку является **понижением версии**, а не обычным обновлением: не полагайтесь на совместимость сохранённых данных. Используйте чистую установку и осознанное восстановление совместимых настроек.

## 6. CLI: чистая установка

**Следующая команда стирает все настройки, ключи, сопряжения и историю. Выполняйте её только если вы сами выбрали чистую установку и уже сохранили резервные копии.**

В каталоге `dist/`, в режиме загрузчика:

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX erase_flash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX --baud 115200 --after no_reset write_flash 0x0 meshtastic-e290-inkhud-ru.factory.bin 0x340000 mt-esp32s3-ota.bin 0x670000 littlefs-e290-inkhud-ru.bin
```

После записи выполните `python start_firmware.py --port /dev/cu.usbmodemXXXX` с портом загрузчика. Скрипт очищает флаг ROM download и запускает приложение штатным watchdog-reset; Flash не меняется. Он требует установленный выше `esptool==4.11.0`. На проверенном Mac порт сменился с короткого `usbmodem...` на порт с идентификатором устройства — это нормально.

После запуска настройте регион и каналы в приложении под своё оборудование и место использования. При необходимости восстановите совместимые настройки через `meshtastic --port PORT --configure e290-config.yaml`. Полный сброс может изменить ключ идентичности; повторно проверьте связь с доверенными узлами и BLE-сопряжение.

Штатный `firmware/bin/device-install.sh` версии 2.7.26 здесь **не рекомендуется**: он вычисляет `SPIFFS_OFFSET` из манифеста, но использует переменную `OFFSET=0x300000` при записи. Таблица E290 требует `0x670000`. Команды выше используют фактический адрес.

## 7. Восстановление и возврат

Если нет запуска: проверьте питание и кабель, войдите через BOOT в загрузчик, снизьте скорость до 115200 и повторите запись правильного набора. Не нужно менять пины или подключать программатор к LoRa-модулю.

Официальные оригинальные файлы **E290 InkHUD 2.7.26** сохранены в `official/` из [официального релиза](https://github.com/meshtastic/firmware/releases/tag/v2.7.26.54e0d8d). Их контрольные суммы входят в общий список.

Чтобы вернуть официальную 2.7.26, сохранив настройки после RU-сборки:

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX --baud 115200 --after no_reset write_flash 0x10000 official/firmware-heltec-vision-master-e290-inkhud-2.7.26.54e0d8d.bin
```

При необходимости чистого восстановления используйте шаг 6, заменив factory и littlefs файлами из `official/` и оставив `mt-esp32s3-ota.bin`. Либо установите подходящий официальный E290 InkHUD через Web Flasher, учитывая указания к выбранному релизу.

Полный побайтовый backup возвращается на **то же устройство** записью `e290-full-backup.bin` по адресу `0x0`; это перезаписывает область размером с файл копии и требует отдельного осознанного решения пользователя.

## Частые проблемы

- **`The port is already open` / `Failed to open serial port`:** полностью закройте Chrome/Edge и другие serial-клиенты. На macOS найдите владельца порта через `lsof /dev/cu.usbmodemXXXX`. Браузер может удерживать порт после закрытия вкладки. Затем используйте CLI выше.
- **`waiting for download`, экран не меняется после записи:** отпустите BOOT и нажмите RST. Если остаётся загрузчик, выполните `python start_firmware.py --port PORT`. Это исправило запуск на проверенном устройстве.
- **Порт исчез при сбросе на 1200 baud:** устройство могло успешно перейти в загрузчик и получить другое имя порта; повторите `python -m serial.tools.list_ports`.
- **Цифры часов оставляют следы:** используйте релиз с исправлением минутного обновления. Начиная с v1.2.0 перед рисованием очищается буфер, используется быстрое обновление и периодическая полная очистка: обычный режим 1/10 минут, экономный 5/30 минут. Защита панели может очищать её раньше. Переключение: Экран → Заставка → Режим.
- **Время `--:--`:** подключите клиент Meshtastic, синхронизируйте время и задайте часовой пояс.
- **Нет связи после чистой установки:** заново задайте правильный регион и каналы, проверьте ключи каналов и BLE-сопряжение. Чистая установка создаёт новую идентичность устройства.

## 8. Приёмка на устройстве

Проверьте все десять строк из ТЗ, длинные имена, длинное слово, пустые строки, оба тайла и поворот экрана; All Messages, DMs, Threaded Message, Heard, Recents List, карту с короткими именами, меню каналов и уведомления. Затем LoRa-приём/отправку с обычным узлом, BLE и мобильное приложение, Wi-Fi, настройки после перезапуска, кнопки, обновление и возврат к официальной версии. Сравните читаемость, ghosting, частичные/полные обновления и ток потребления с оригиналом.
