# Изменения E290 InkHUD RU

База: Meshtastic 2.7.26.54e0d8d Beta, commit `54e0d8d0ab2ff56b3a9ce967e53f79e49af560fb`.

- v1.1.0: на заставке добавлены значок батареи и процент заряда из штатного PowerStatus; отсутствующие данные отображаются как `--%`.
- Исправлено наложение цифр: заставка очищает буфер перед отрисовкой и выполняет полное обновление E-Ink каждую минуту.
- Заставка: часы/дата слева, список непрочитанных справа; ручное включение и авто 1/5/15 минут.
- Блокировка кнопок с выходом по удержанию основной; таймер сохраняется без изменения штатной структуры настроек.
- Ограниченная очередь 20 входящих сообщений в RAM, защита от дублей, учёт просмотра и команда «Прочитать всё».
- Добавлены тесты таймеров, кнопок, адресации, очереди и программный рендер заставки.
- Полная русская локализация InkHUD: 229 строк, включая меню, подсказки, статусы, уведомления и названия экранов.
- Перевод включён только для E290; пользовательский текст и служебные идентификаторы сохранены.
- Уплотнена компоновка подсказок; реальные методы Tips/Menu проверены в обеих ориентациях экрана.
- Исправлен размер буферов процентов для значения 100% и ограничена запись через snprintf.
- E290: FreeSans Windows-1251 вместо Windows-1252, размеры 6/9/12 pt.
- Строгое декодирование UTF-8 с fallback и нормализацией переводов строк для экрана.
- Полные метрики кириллических шрифтов и глиф математического минуса U+2212.
- Исправлены перенос длинных слов, точное заполнение строки, границы блока и частичная последняя строка.
- Общая функция усечения учитывает ширину строки вместе с многоточием; применяется к именам, заголовкам, меню и уведомлениям.
- Устранено двойное перекодирование имени отправителя в уведомлениях.
- Размер шрифта сообщения выбирается с учётом высоты заголовка.
- Добавлены host-тесты под ASan/UBSan и программный рендер в PNG.

Изменения ограничены графической подсистемой. Аппаратные испытания — отдельный этап приёмки.
